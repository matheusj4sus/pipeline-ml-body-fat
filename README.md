# Pipeline de Machine Learning: % de gordura corporal

Pipeline completo em Python e Google Colab, com duas etapas sobre o dataset público Body Fat: **regressão** (prever o percentual de gordura corporal) e **classificação** (categorizar os casos).

## Etapas
- Análise exploratória e limpeza de dados justificada
- Prevenção de data leakage
- Comparação de 6 algoritmos com validação cruzada e ajuste de hiperparâmetros
- Avaliação por RMSE e R² (regressão) e por F1, precisão e recall (classificação)

## Notebooks

- [Q2 – Classificação](COLE_AQUI_O_NOME_DO_ARQUIVO_Q2.ipynb)
